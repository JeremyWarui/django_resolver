## Running Tests

Run all pytest tests:
  .venv/bin/pytest tickets/tests/ -v

Run specific test file:
  .venv/bin/pytest tickets/tests/test_models.py -v

Run specific test:
  .venv/bin/pytest tickets/tests/test_models.py::test_user_creation -v

Run tests matching pattern:
  .venv/bin/pytest -k "user" -v

Run with coverage:
  .venv/bin/pytest tickets/tests/ --cov=tickets

Run excluding slow tests:
  .venv/bin/pytest -m "not slow" -v
